# Novoriamon NPC-Skins – Signature Pass V4

45 PNG-Skins (64×64 RGBA, Classic/Steve) plus 45 vierseitige Vorschauen. IDs und Dateinamen aus V3 bleiben erhalten. Anders als bei einer massenhaften Neufärbung wurden die früheren markanten Charaktermerkmale bewusst betont; besonders Kael (Fire Gym) hat wieder kräftiges rotes Haar. Die Farb- und Frisurentscheidung ist pro Figur in `SKIN_ZUORDNUNG.csv/json` erfasst.

## Installation
Für EasyNPC die Dateien unter `skins/` verwenden, nicht die Vorschaubilder. Skin-Modell Classic/Steve. Die gehosteten Dateien lassen sich nach Upload zu GitHub ggf. mit `https://raw.githubusercontent.com/Tirlian/Skinsrepo/main/gym_fire.png` abrufen, wenn die Dateien direkt im Repo-Stamm liegen und EasyNPC diesen Host akzeptiert. Bei ungültigem Remote-Bild lokalen Import oder eigenen Texturhost verwenden.

## Qualität und Grenzen
Technisch geprüft: 45 eindeutige RGBA-PNGs, UV-Bereiche deckend. Die Vorschau ist eine flache Projektion der Skinflächen, kein Minecraft-3D-Render. Der Skin-Stil wurde automatisch und pro Rolle angepasst, aber noch nicht einzeln durch professionelle Pixelart-Artists gezeichnet; künstlerische Abnahme sowie EasyNPC-Ingame-Test sind weiterhin offen. Keine Änderungen an GitHub vorgenommen.
